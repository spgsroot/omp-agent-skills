# Сигналы строгости

Кто решает, сколько инженерии нужно задаче: **пользователь — своими словами,
в текущем запросе**. Агент не эскалирует выше сигнала сам. Нет сигнала —
прямой путь.

## Карта

| Сигнал пользователя (примеры слов) | Уровень | Что делает агент |
|---|---|---|
| — (молчание, обычный запрос) | **default** | правка → затронутые тесты → коммит. Штатные проверки репо (существующий `check`/CI), ничего сверх |
| «набросай», «спайк», «just try», «эксперимент» | **spike** | быстрый набросок без тестов и полировки; помечен как throwaway; рефакторить/чистить — только по отдельному запросу |
| «тщательно», «аккуратно», «не сломай», «проверь граничные» | **careful** | + покрытие граничных случаев затронутой области, полный прогон затронутых тестов, регресс-тест на найденный баг |
| «все проверки», «полные гейты», «gate full» | **full** | eng-gates `gate full` (зависимости, мёртвый код, CRAP/дубликация/мутации точечно, бенчмарки hot-path) |
| «оверинжинь», «сделай по полной», «production-grade», «как для продакшена» | **max** | полный цикл: SDD (план → волны имплементеров → ревью) + `gate full` + ревью всей ветки |

Правила:

1. **Сигнал живёт одну задачу**, включая её уточнения и продолжения.
   Новый независимый запрос начинает с `default`, если пользователь не задал
   другой уровень.
2. **Вниз — всегда можно**: агент может предложить меньший уровень («это
   правка одной строки, хватит fast-проверок»), вверх — никогда сам.
3. **Сомнение между двумя уровнями — брать нижний** и назвать выбор.
4. Задача выросла (правка превратилась в рефакторинг трёх модулей) — агент
   **останавливается и спрашивает**, эскалировать ли уровень, а не делает
   это молча.

## Для скиллов

Предметные скиллы выбираются по задаче и `description`: писать README —
`writing-docs`, исследовать бинарник — `reversing`, координировать уже нужных
агентов — `coordinating`. Специальных слов строгости для них не требуется.

Сигнал управляет **дополнительным процессом**: полные гейты, SDD, отдельный
план и циклы ревью не включаются только из-за ссылки из другого скилла.
Явный запрос конкретного скилла или процесса также считается сигналом.
Для Superpowers действует тот же выбор: скиллы доступны по задаче, но
обязательный bootstrap отключён; `max` включает полный цикл, а не любой
запрос на изменение кода.

`eng-gates` включается на `full`/`max`, при явном запросе настройки гейтов
или исправления упавшего существующего гейта — не после каждой правки.
Штатные проверки проекта, требования безопасности и явно обязательные
правила репозитория остаются обязательными на любом уровне.

Главный агент передаёт выбранный уровень и нужные ограничения в задания
субагентам: пользовательский `AGENTS.md` автоматически им не наследуется.

## Установка как глобального контекста

Добавьте этот раздел в пользовательский `~/.omp/agent/AGENTS.md`, сохранив
несвязанные пользовательские предпочтения. Старые требования безусловного
SDD и `gate full` удалите: простое добавление карты не устраняет конфликт.

Сигналы действуют в новых сессиях omp. Локальный `AGENTS.md` репозитория
добавляет требования стека и команд проекта; карта не ослабляет обязательные
проверки. После изменения глобального контекста начните новую сессию.
